请在首次使用前仔细阅读本说明书。如果你已经穿越了才读到这段话——没关系，反正你迟早会读到。毕竟它永远迟到36年。

## 操作指南

### 出发前检查
1. 确认小皮已进入笼子——如果她还在驾驶舱，目的地可能被改为侏罗纪
2. 确认菲球没有偷喝猫耳娘药水——醉醺醺的吉祥物会造成导航混乱
3. 检查瓦斯储备——冬季尤其重要
4. 随身携带薯条——穿越途中可能会饿

### 设定目的地
1. 在控制面板输入目标年份（请注意：实际到达年份 = 目标年份 + 36）
2. 如果你想去1985年，请输入1949年
3. 如果你想去现在，请随意输入——反正都到不了现在，到的永远是"现在+36年后"
4. 不要问为什么不修这个 bug（问就是特色功能）

### 穿越途中
- 不要看书——会晕机
- 不要吃东西——薯条会飘进控制面板（已发生多次）
- 不要试图调整目的地——中途变道会触发威尔士民谣循环播放，无法关闭
- 如果听到1885年民谣，请放松享受——这是时光机的背景音乐，关不掉

### 到达后
- 深呼吸，确认自己没有老36岁
- 检查小皮是否还活着（她通常是第一个冲出时光机的）
- 确认当前不是侏罗纪（如果恐龙在看着你，回到上一步）

## 已知故障及应对

### 故障1：迟到36年
- **症状**：设定目的地为100年后，实际到达136年后
- **原因**：未知（研发中）
- **应对**：提前36年出发

### 故障2：冬季瓦斯不足
- **症状**：引擎在寒冷天气熄火
- **原因**：1885年威尔士的供暖系统依赖"手动获取"瓦斯
- **应对**：携带备用瓦斯。或选择在夏季穿越

### 故障3：随机播放威尔士民谣
- **症状**：穿越过程中不可控地播放1885年民谣
- **原因**：塔菲的童年记忆被固化为音频模块
- **应对**：无法关闭。跟着哼唱可能会让你好受一些

### 故障4：小皮干扰
- **症状**：兔子进入驾驶舱，啃咬控制面板，把胡萝卜塞进燃料舱
- **原因**：小皮
- **应对**：出发前将她锁进笼子。如果失败，接受侏罗纪之旅

## 安全警告

1. 载重不超过129.3kg
2. 孕妇、心脏病患者、对时空悖论过敏者请勿使用
3. 使用时光机改变历史的后果自负——虽然历史似乎已经证明你没有成功改变任何东西
4. 不要尝试在时光机里洗澡——它没有浴室，而且水会漏进引擎

## 保修条款

本产品享有永雏塔菲终身保修——只要你能找到她，且她当时没有在修另一台时光机、吃薯条、追菲球。保修不包括爆炸（Mark I和II已证实）、迟到（设计如此）以及小皮造成的损坏。
